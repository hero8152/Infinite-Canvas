# ListenHub 画布接入工具与操作指南

本文件夹（`E:\ListenHub配置工具`）包含为您专属定制的 Infinite-Canvas 画布 ListenHub 接入工具与完整配置指南。

---

## 📂 文件清单与运行顺序

1.  **`一键配置ListenHub.bat`** **【双击优先运行它】**
    *   **作用**：一键执行工具。它会自动搜索您的 `Infinite-Canvas` 目录，并自动使用项目内的便携 Python 来修改代码，无需您手动操作命令行。
2.  **`patch_listenhub.py`** 【核心脚本，由上面的 .bat 调用】
    *   **作用**：底层 Python 补丁文件。它负责在 `main.py` 中安全注入 ListenHub 生图路由、多模态参考图传递、尺寸比例自动换算，以及连接验证拦截逻辑。
3.  **`ListenHub配置与操作指南.md`** 【本指南】
    *   **作用**：提供详细的操作步骤和使用说明。

---

## 🛠️ 第一阶段：一键配置接入步骤（仅需在每次更新画布后执行一次）

1.  **双击运行 `一键配置ListenHub.bat`**。
2.  **路径自动搜索与确认**：
    *   脚本会自动搜索常见的项目目录（如 `E:\Infinite-Canvas`、同级目录、当前目录等）。
    *   如果脚本自动找到了您的 `main.py`，会直接提示备份并显示 `✓ 成功应用补丁`。
    *   **如果未自动找到**，窗口中会提示：`请输入您的 Infinite-Canvas 根目录路径`。此时您只需将您的画布项目文件夹路径（例如 `E:\MyCanvas`）复制粘贴进去，按下回车即可。
3.  **显示成功**：窗口中显示 `🎉 恭喜！所有 ListenHub 接口补丁已成功注入！` 后，按任意键退出。

> [!TIP]
> **关于升级**：如果您以后使用 Git 或者下载网盘包**覆盖更新/升级了画布**，导致 `main.py` 恢复为官方默认状态。您只需要**重新双击运行一次**本目录下的 `一键配置ListenHub.bat`，即可一键重装支持！

---

## 🧭 第二阶段：网页后台配置（仅需在首次使用时配置一次）

1.  **启动本地服务**：
    *   进入您的画布文件夹，双击运行 **`启动服务.bat`**（或 `run.bat`）。
    *   浏览器打开 `http://127.0.0.1:3000/`。
2.  **进入 API 配置**：
    *   点击网页左下角的 **“API 设置”**。
3.  **新增提供商**：
    *   点击 **“新增 API”**，填写以下信息：
        *   **请求地址 (Base URL)**：`https://api.marswave.ai/openapi`
        *   **协议 (Protocol)**：选择 **“OpenAI 直连”**（我们的后端会自动检测并替换为 ListenHub 专属协议）。
        *   **API Key (密钥)**：粘贴您在 ListenHub 平台获取的 `lh-...` 密钥。
4.  **验证与拉取模型**：
    *   点击 **“验证地址”** 与 **“验证协议”**，出现绿色的对勾（✓）。
    *   点击 **“拉取模型”**。此时系统会拦截并展示为您配置好的专属模型。
    *   勾选 **`openai/gpt-image-2`**、**`google/imagen`**、**`pixverse`**。
5.  点击底部的 **“保存”**。

---

## 🎨 第三阶段：在画布上生图与使用

1.  在画布空白处 **右键** ➔ 选择 **“图像生成”** 节点。
2.  在节点的右侧设置中：
    *   **提供商 (Provider)**：选择您刚才添加的 **ListenHub**。
    *   **模型 (Model)**：下拉选择 **`openai/gpt-image-2`** 或 `google/imagen`。
3.  **文生图**：在 Prompt 输入框中填写描述词，点击 **“生成”**。
4.  **图生图/参考图**：添加图片节点，将其引脚连线拉入该生图节点的 **“参考图”** (Image) 输入端口，系统会自动将图片编码打包并以图生图的模式发给 ListenHub。

---

## ⚠️ 参数规格限制提示
*   **余额限制**：由于校验连接时会发起极小额请求，**您的 ListenHub 账户内必须保留至少 1 元的积分余额**，否则验证会失败。
*   **尺寸限制**：`gpt-image-2` 模型长边最大为 3840 像素，总像素最高约 829 万。如果您选择的分辨率超限，接口会报错并给出友好提示，此时只需调小尺寸即可。
*   **超长超时等待**：由于生图尤其是高分辨率生图耗时较长，我们已将 ListenHub 通道超时时间延长至 **1800 秒**，生图期间请耐心等待。
